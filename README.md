
# genai-creator-lab2 — AI 302: Train Your Own Small LLM

To view the workshop, please go here: [GitHub Pages Link](https://fortinetcloudcse.github.io/genai-creator-lab2/)

A hands-on lab in which participants pre-train a small GPT-style language model from scratch in
Google Colab, then run inference with different sampling strategies. Approx. 3 hours.

Related workshops:

- [AI 301 - Building Supervised ML Models](https://fortinetcloudcse.github.io/genai-creator-lab/) — the prerequisite for this lab
- [AI 101 - Agents, MCP & the Agentic Security Model](https://fortinetcloudcse.github.io/ai-101/index.html) — what gets built on top of LLMs, and how it is attacked

The complete, runnable solution is in [`solution/genai_lab_solution.ipynb`](solution/genai_lab_solution.ipynb).
