You have a tokenizer, embeddings and a decoder block. Now you will assemble the full model, learn the
one objective that trains every LLM — **next-token prediction** — and run the training loop that
turns random weights into a model that has actually learned the structure of language.

**Approx. time:** 40 minutes (including the training run)
